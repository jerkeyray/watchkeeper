# Final report artifacts

[Watchkeeper Final Project Report](Watchkeeper_Final_Project_Report.pdf) is the submission PDF. Its editable source is [`../final-project-report.md`](../final-project-report.md). The document contains final implementation, architecture, technology, comparative contribution, evaluation, reproducibility, and limitations rather than proposal-stage promises.

Vector figures under `assets/` are generated by [`../../scripts/build-report.py`](../../scripts/build-report.py) and embedded directly into the PDF. To rebuild, use Python 3 with ReportLab installed:

```sh
make report
```

No database, Docker service, or experiment rerun is needed to rebuild the document. Rebuilding changes presentation only; the retained evidence lives separately under [`../evidence/`](../evidence/README.md).
